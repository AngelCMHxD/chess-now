Messages sent by `ChessNowClient` over the WebSocket connection. The client sends these automatically when you call `subscribe()`, `watchDeviceAuth()`, `matchSubscribe()`.

## ClientMessage

The union type for all outgoing messages.

### `subscribe`

Sent when you call `client.subscribe(token, events)`. The server authenticates the token and subscribes the connection to the requested event channels.

  path="packages/api/src/types/ws-messages.ts"

/>

### `watch_device_auth`

Sent when you call `client.watchDeviceAuth(userCode, deviceCode)`. The server starts watching the device auth flow and sends back events when the user approves or denies.
