Messages sent by `ChessNowClient` over the WebSocket connection. The client sends these automatically when you call `subscribe()`, `watchDeviceAuth()`, `matchSubscribe()`.

## ClientMessage

The union type for all outgoing messages.

  path="packages/api/src/types/ws-messages.ts"

/>

### `subscribe`

Sent when you call `client.subscribe()`. The server subscribes the connection to the requested event channels.

<AutoTypeTable
  path="packages/api/src/types/ws-messages.ts"
  name="SubscribeMessage"
/>

### `match_subscribe`

Sent when you call `client.matchSubscribe()`. The server subscribes the connection to the requested match. You'll receive all match events as if you are a player in that match.

<AutoTypeTable
  path="packages/api/src/types/ws-messages.ts"
  name="MatchSubscribeMessage"
/>

### `watch_device_auth`

Sent when you call `client.watchDeviceAuth(userCode, deviceCode)`. The server will notify when the user approves or denies the device auth, or if it expires
